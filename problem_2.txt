ENVIRONMENT
  OS: Windows 11 + WSL2 Ubuntu; Java: OpenJDK 11; Hadoop 3.4.3 (local/standalone mode)
  Libraries: opennlp-tools-1.9.3.jar (PorterStemmer), stopwords.txt
  Preprocessing (identical in 2a and 2b): lowercase -> split on [^a-z0-9]+ -> drop empty
  -> drop stop words -> PorterStemmer.stem. Doc ID = article file name without ".txt".

  Output: df_all (TERM<TAB>DF), top100_df.tsv, inverted_index (TERM<TAB>DOC:TF,DOC:TF,...)

PART 2(b)  Query retrieval
  Index line format: TERM<TAB>DOC_ID1:TF1,DOC_ID2:TF2,...   (DF = number of postings)
  N = total number of documents (50 for the sample set; <count> for the full set).
  Query terms are lowercased, stop-word filtered, stemmed and DEDUPLICATED into a set Q.

  Compile + run (from the project folder):
    ./run_query.sh <inverted_index_dir> <N> "<query string>" output_query
  which does:
    javac -cp $(hadoop classpath):opennlp-tools-1.9.3.jar QueryRetrieval.java
    jar cf problem2_query.jar QueryRetrieval*.class
    export HADOOP_CLASSPATH=$PWD/opennlp-tools-1.9.3.jar
    hadoop jar problem2_query.jar QueryRetrieval -libjars opennlp-tools-1.9.3.jar \
        stopwords.txt <inverted_index_dir> output_query <N> "<query string>"
  Output: output_query/part-r-00000 :  RANK<TAB>DOC_ID<TAB>MATCHED_TERMS<TAB>SCORE (top 10,
  score desc, ties by DOC_ID asc, score printed with 6 decimals; ln used for IDF).
  Cross-check: python verify_retrieval.py <index.tsv> <N> "stem1,stem2"
